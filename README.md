# Majid Salim Technical Services L.L.C — Website

Bilingual (English / Arabic) one-page website for a UAE Civil & MEP manpower supply company.

- `index.html` — the whole site (HTML, CSS and JS in one file)
- `assets/img/` — photos (public domain / CC0, from rawpixel and Wikimedia Commons via Openverse)
- `assets/logo/` — logo, favicon and social share image

Enquiry and job-application forms open WhatsApp with a pre-filled message to +971 52 124 9137; no server is needed.

To update: edit `index.html`, commit and push to `main` — GitHub Pages redeploys automatically.
